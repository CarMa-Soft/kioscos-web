# Kioscos y Almacenes

Punto de venta web para kioscos y almacenes: ventas, caja, stock, clientes, compras y proveedores. En desarrollo.

- La app (`app/`) es HTML, CSS y JavaScript sin compilar, publicada en GitHub Pages.
- La base de datos es Supabase (Postgres) con reglas de seguridad por negocio. Sus cambios están en `supabase/migrations/`.

Para probarla en la computadora: `node tools/servidor.js` y entrar a http://localhost:5180.

Este código es visible, pero no tiene licencia de uso: todos los derechos reservados.
Para avisar de una falla de seguridad, usar **Security → Report a vulnerability**, no un issue público.
